# Gradebook-Project
This project is a very simple grade management GUI system.

The user is able to navigate pages by clicking buttons and inputting text into text fields.

The first page serves as a main hub, where the user will either be able to choose to input a new grade, or view previously inputted grades.

If the user inputs a new grade, they will have to fill out all the text fields with valid inputs (Strings for assignment, class, and student names; floats/ints for total points and points correct). Once all inputs are valid, it will return the user to the main hub, where they will be able to input another grade or look at all of the grades.

If the user wants to view grades, they will be able to filter by a specific student, class, or assignment by typing in the text fields, or if they want to view all grades, they will be able to do so by clicking a button.

Both the page where the user can filter the grades that they want to view and the page containing the grades have a back button to return to the main hub.
